# Сравнение TU-эвристик (cbench)

Все числа — на наборе **cbench** (23 translation unit-а, полные модули, baseline = `-O0`).
Основная метрика — **macro vs `-Oz`**: для каждого бенчмарка
`(oz_size − result_size) / oz_size`, затем невзвешенное среднее по 23 бенчмаркам
(каждый весит одинаково). Положительное значение = эвристика меньше вывода `-Oz`.
Дополнительно: суммарно сэкономленные байты `.text` и инструкции, и на скольких
бенчмарках результат лучше `-Oz` по `.text`.

| Эвристика | macro vs `-Oz` | −.text Б (всего) | −instr (всего) | лучше `-Oz` |
|---|--:|--:|--:|--:|
| `segment_tree_beam` | **14.37%** | 671,605 | 112,287 | 20/23 |
| `segment_tree` | **13.55%** | 646,322 | 106,839 | 20/23 |
| `strong_links` | **13.12%** | 651,659 | 107,286 | 20/23 |
| `measured_superpath` | **13.07%** | 634,758 | 102,629 | 20/23 |
| `flow_paths` | **12.34%** | 619,084 | 99,616 | 20/23 |
| `cycle_breaking` | **12.09%** | 615,810 | 99,708 | 19/23 |
| `bucket_dag_teacher` | **10.99%** | 604,803 | 96,074 | 19/23 |
| `random_walk_1000` | **8.37%** | 594,986 | 95,096 | 18/23 |
| `-Oz` (baseline) | 0.00% | 498,577 | — | — |

По метрике macro vs `-Oz` лидирует `segment_tree_beam`; все TU-эвристики в
среднем обходят `-Oz` (на мелких модулях `-Oz` часто раздувает код, и там выигрыш
особенно велик — `crc32`, `blowfish`, `adpcm`).

## Методы (кратко)

- **segment_tree_beam** — измеренные 4-пассовые сегменты из графа порядка пассов
  становятся листьями сбалансированного бинарного дерева; на каждом узле — beam-
  поиск с операцией include/skip над обоими порядками конкатенации (выбор лучшей
  подпоследовательности по измеренному на TU `.text`), гарантированно не хуже
  best-prefix; ширина beam масштабируется по размеру модуля.
- **measured_superpath** — двухволновой обучающийся поиск: измеренные 4-пассовые
  супер-вершины, ε-жадно сэмплируемые супер-рёбра с онлайн-обучением синергии,
  затем beam-поиск суперпутей длины 2..5 на измеренном супер-графе.
- **strong_links** — майнинг частых непрерывных подотрезков пассов (встречающихся
  в ≥2 функций) как листьев; бим-слияние по дереву, направляемое рёбрами графа.
- **segment_tree** — те же 4-пассовые листья, детерминированное попарное слияние по
  дереву (пробуются оба порядка, хранится лучший префикс).
- **flow_paths** — послойная max-flow декомпозиция графа по длинам путей; двухволновой учитель.
- **cycle_breaking** — удаление циклов (только прямые рёбра), DP top-k путей в DAG; TU-учитель переоценивает рёбра.
- **bucket_dag_teacher** — ранжирование вершин по исходящему весу, бакеты, ацикличный DAG, DP top-k; TU-учитель.
- **random_walk_1000** — взвешенные случайные блуждания по графу порядка; измерение на TU; лучшее.
